🔒 Security First

All 22 tools are strictly read-only. All data is automatically sanitized — PII, secrets, tokens, and credentials are redacted before reaching your AI assistant. Communicates over stdio via kubectl exec — no ingress, no API keys, no new attack surface.

About Us

KubeOpsAI builds Kubernetes observability tooling for AI assistants.

We build tooling that connects AI assistants to Kubernetes clusters, enabling engineering teams to query their observability stack using natural language instead of manually navigating dashboards.

Our flagship product, K8s Telemetry MCP Server, implements the Model Context Protocol (MCP) — an open standard that allows AI assistants like Amazon Q, Claude, and Bedrock agents to call external tools and retrieve structured data.
